⚠ Connect your Supabase project

This dashboard reads live data through Supabase's REST API. It won't show numbers until you point it at your project.

  1. In this file, find the CONFIG block near the bottom of the <script> and set SUPABASE_URL and SUPABASE_ANON_KEY (Supabase dashboard → Project Settings → API).
  2. Run bi_views_for_dashboard.sql once in the Supabase SQL Editor — it creates the public.v_* views this file fetches, plus the HR views your proposal needs, and grants SELECT to the anon role.
  3. Save this file and reopen it in your browser.

Using the anon key here is expected for Supabase's client-side model, but it makes these views world-readable to anyone with the file. Fine for an FYP demo; for anything real, put these views behind RLS or Supabase Auth first.
